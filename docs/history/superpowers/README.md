# Build-session artifacts (historical)

These files are internal AI build-session artifacts (implementation plans and
design specs from the sessions that produced this repository). They are **not
consumer documentation**: they describe what was *planned* at a point in time,
not what the code does today, and they are not updated when the code changes.
